Endpoints de la API REST

Haga clic en cualquiera de los enlaces a continuación para consultar los datos en formato JSON directamente desde su navegador:

GET /api/v1/videojuegos
Listar todos los videojuegos (Template Method getAll)
JSON
GET /api/v1/videojuegos/activos
Listar sólo videojuegos activos (baja lógica = false)
JSON
GET /api/v1/categorias
Listar todas las categorías (Template Method getAll)
JSON
GET /api/v1/estudios
Listar todos los estudios de desarrollo (Template Method getAll)
JSON
Operaciones CRUD Disponibles (Vía Postman / cURL):
  • POST /api/v1/videojuegos - Crear un videojuego (Cuerpo JSON).
  • GET /api/v1/videojuegos/{id} - Obtener un videojuego por ID.
  • PUT /api/v1/videojuegos/{id} - Actualizar videojuego.
  • DELETE /api/v1/videojuegos/{id} - Baja lógica (Soft delete).
  • GET /api/v1/videojuegos/search?query=... - Búsqueda por título.
